Эта папка для написания web интерфейса карты пожаров.

# Изоляция сервиса

Сервис не импортирует ничего из `src/`. Если в `service/` появится
`import inference` или `import rle` — это ошибка архитектуры.

Данные сервис берёт только из `service/data/*.geojson`.
Формат этих файлов — контракт с основным пайплайном (см. ТЗ, раздел 2).

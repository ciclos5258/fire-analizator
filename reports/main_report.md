**Наблюдение:** IoU(1) почти не улучшается (0.25 → 0.24 → 0.09 при +0.10) —
порог не лечит фундаментальную проблему класса 1 (фенология, пашня).
Нужен либо RdNBR, либо ML-подход.

1. Наблюдение: 127 AF-чипов полностью NaN, из них 89 с `n_fire_px > 0`.  
   Решение: исключить из train-оценки. Использовать `valid = ~np.isnan(I1)`.

2. Наблюдение: `valid_frac = 1.0` в meta не соответствует реальности.  
   Решение: не доверять `valid_frac` из meta, использовать маску из растра.

3. Наблюдение: 12.25% fire-пикселей теряются физически.  
   Решение: пересчитать F1 честно, указать в отчёте заниженную оценку baseline.

4. Наблюдение: полосы и клинья в 163 частичных чипах.  
   Решение: не считать NaN-области за FP — они исключены маской валидности.
